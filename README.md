# String Manipulation Toolkit

A simple Java text analysis tool with functions for basic string manipulation.

## Features
1. String Reversal
2. Palindrome Checker
3. Anagram Checker
4. Word Count
5. Character Count (excluding spaces)
6. Substring Finder
7. Lower Case Converter
8. Upper Case Converter
9. Vowel Remover
10. Consonant Remover

## How it Works
The user selects an option (1-10) from the menu, then enters a string (3 sentences) to be processed based on the chosen option. Invalid inputs outside 1-10 are not accepted.
